# 美化模块库

本文件是所有输出类型共用的美化模块库。模块按功能分类，可以在 A4、HTML PPT、交互网页 PPT、小红书、手机长图、信息图、HTML 页面之间互换组合。

## 使用方式

1. 先读对应类型文件，确定本类型的固定功能区和画布比例。
2. 根据用户题材和内容需求，从本库选择每个功能区需要的模块。
3. 固定画布类型用 `vw` / `vh` 直接描述尺寸；自然高度类型换算成固定 px 或 `vw`。
4. 模块只负责美化，不改变 `.sheet` 分页、`@page`、文字可复制等硬规则。

## 构成流程（封面页 / 内页分开约束）

构成优先于模板：拿到内容先分析、选模块、再构成画面，禁止 100% 照搬模板出品。

【封面页】位置自由，重心明确
- 主层（标题/介绍）是画面唯一视觉中心；位置由内容和用户要求决定，左上、居中、右下等都可以，不强制“中心锚点 + 四角分布”。
- 重心自检参考（可选，非强制）：固定画布类型（A4 / PPT / 小红书 / 信息图）主层内容区建议不超过画布高 80%；任一侧留白超过另一侧 2 倍时，重新审视重心是否成立。
- 自适应类型（手机长图 / HTML 页面）按内容流自然构成，不套用固定画布的封面锚点规则。
- 四角/边沿锚点只是可选方案，不是默认结构；如果使用，可按权重配置，组合可自由增减替换，用户不喜欢就换。
- 锚点权重顺序：主层在左上 → 左下 → 右下 → 右上；主层在中心 → 上 → 下（按阅读顺序上先于下；如内容需要也可下重上轻，但全篇方向一致）；主层在右下 → 右上 → 左上 → 左下；其他角位按“同侧垂直远端 → 对角远端 → 同侧水平远端”类推；同一文档内锚点递减方向遵循同一逻辑，位置可以不同。
- 权重由重到轻一般对应：文字标签 → 大号淡页码 → kicker 小标 → 装饰点；可按内容替换（A4 的 kicker 对应眉标 / eyebrow）。
- 模块从 A（结构）类选 1 个做主层骨架，B（标题）类选 1 个做标题层级；锚点如使用，按权重配置。
- 硬边界：页边距（画布到内容区的留白）与全篇一致、无溢出、无重叠、有明确视觉重心、风格语言（色板/字体/装饰密度）一致；主层移动只发生在内容区内部。

【内页】模块构成自由
- 内页没有固定四件套（kicker + 大标题 + 卡片网格 + rule 不是默认结构）。
- 每页先分析该页内容的功能（数据 / 对比 / 流程 / 引文 / 清单 / 时间线…），再从本库挑选匹配模块构成；允许非对称、单卡、无卡片、数据格、引文大字等版式。
- 自由度边界：① 页面有明确视觉主层（一个重心，不散漫）；② 间距、页边距、对齐与全篇一致（全局统一，局部自由）；③ 无溢出、无重叠；④ 同类型页构成可以不同，但风格语言（色板 / 字体 / 装饰密度）保持一致。
- 用户不满意某页构成时，单页重构成，不动其他页。

## 排版阶段第一要素：间距 / 页边距 / 对齐

前提：必须先完成提问，收集足够信息后再进入排版；信息不足时不开始生成。

- 页面四边留白统一，按类型固定；模块不得自定义页边距。
- 模块间距统一：功能区之间间距 > 模块间距 > 卡片间距。
- 同类模块对齐：同排顶部/底部对齐、网格关系清晰；用 grid/flex，禁止随机绝对定位。
- 框框模块是自由框：宽度和高度都可以波动，只要画面信息密度平衡。
- 装饰模块不参与内容对齐，绝对定位只用于幽灵数字、印章、红条等装饰。
- 先定间距和骨架，再填模块内容；框框模块高度波动不能破坏间距和对齐。

## 各类型 vw/vh 基准

固定画布导出和截图时，视口会被锁成画布尺寸，所以 `vw` / `vh` 是稳定值：

注意：长 PNG 会把视口高度拉长，`vh` 不再等于单页 1vh；标准管线导出长图时会用固定 px 覆盖 `vh` 变量。

| 输出类型 | 1vw | 1vh | 说明 |
| --- | --- | --- | --- |
| A4 摘要（794 × 1123） | 7.94px | 11.23px | 宽度用 vw，上下留白用 vh |
| HTML PPT / 交互网页 PPT（1280 × 720） | 12.8px | 7.2px | 宽度用 vw，高度用 vh |
| 小红书卡片（1080 × 1440） | 10.8px | 14.4px | 宽度用 vw，高度用 vh |
| 信息图（1080 × 1215） | 10.8px | 12.15px | 宽度用 vw，高度用 vh |
| 手机长图 / 连续长文（1080 宽） | 10.8px | 不固定 | 宽度固定，禁止依赖 vh |
| HTML 页面 | 自适应 | 不固定 | 用 vw 或固定 px |

## 比例标准（vw/vh）

- 主标题：8–10vw
- 章节标题：4.5–5vw
- 卡片标题：3–4vw
- 正文：2–2.5vw
- 卡片间距：同功能区 2–3vw
- 块间距：5–6vw
- 卡片内边距：≥3vw
- 页面边距：按类型固定，不由模块决定
- 幽灵数字：25–45vw 高，底部对齐，不能撑高页面；大字号幽灵数字用衬线字体，或加 height:1em + overflow:hidden，否则无衬线下 scrollHeight 虚高导致 check_overflow 误报
- 印章：9–13vw 直径
- 高度相关尺寸（顶部留白、页脚、垂直间距）按类型 `1vh` 换算，不用猜

## 模块间基础间隔

每个模块组合前都要标注基础间隔，不能贴在一起：

| 间隔位置 | A4 | PPT / 交互 PPT | 小红书 / 信息图 |
| --- | --- | --- | --- |
| 模块前间距（上一个模块结束 → 下一个模块开始） | 5vw ≈ 39.7px | 4vw ≈ 51.2px | 4vw ≈ 43.2px |
| 功能区之间（封面→内容→结尾等大区块） | 8vw ≈ 63.5px | 6vw ≈ 76.8px | 7vw ≈ 75.6px |
| 同功能区卡片之间 | 3vw ≈ 23.8px | 2.5vw ≈ 32px | 2.5vw ≈ 27px |
| 标题与正文之间 | 2.5vw ≈ 19.9px | 2vw ≈ 25.6px | 2.5vw ≈ 27px |
| 卡片内边距 | ≥3vw | ≥2.5vw | ≥3vw |
| 页眉/页脚与内容之间 | 5vw | 4vw | 5vw |

垂直方向的间隔优先用 `vh` 表达时，按该类型 `1vh` 换算；间隔值必须写入模板 CSS，不能只靠内容自然堆积。

## 框框模块的尺寸波动

框框模块（C1–C10、A5 步骤卡、A6 时间线卡、A8 观点卡、A10 行动卡、A12 信息表、A13 引用卡等）宽度由网格和画布决定，高度允许较大波动：

- 高度波动范围：基础高度的 1–1.8 倍；内容多时优先加高，不压缩内边距和字号。
- 同一功能区内的框框模块宽度可以不一致；需要视觉对齐时用 `align-items: stretch` 或统一 `min-height`，但不能强行把内容塞成一样大。
- 框框模块必须写 `break-inside: avoid`，避免跨页拆分；必要时写 `min-height` 防止内容被压扁。
- 装饰模块不能决定框框模块尺寸：幽灵数字、印章、红条等绝对定位在框外或角落。
- 如果波动后超出页面，压缩顺序：先缩模块间距，再缩卡片内边距，最后才缩字号；缩完必须通过溢出检查。

## 模块组合规则

- 每个功能区选 1 个主结构模块 + 0–2 个装饰模块。
- 同页最多 1 个视觉焦点。
- 同页不得出现两个功能相同的标题模块。
- 装饰强度按场景：报告/学术 2–3 种，课程/分享 3–4 种，小红书/海报 4 种。
- 结尾页必须与封面同样丰富，不能只放印章或一句感谢。
- 模块跨类型互换时，保留模块结构，但尺寸必须按目标类型的 `vw/vh` 基准重新换算。
- 对齐优先：同排顶部/底部对齐、网格关系清晰；框框模块宽度可不同，但信息密度要平衡；装饰不改变内容对齐。
- 固定画布模板可直接写 `vw` / `vh`；自然高度类型禁止依赖 `vh` / `vmin`，只能用固定 px 或 `vw`。
- 模板模块的大小权重可作参考：允许同类模块替换（如同一功能区卡片、步骤、清单互换），并按视觉中心逻辑移动位置；替换后保持页边距、无溢出、风格一致。
