# 傻瓜式确认问答

## 什么时候先读这个文件

用户请求模糊时先读本文件：

- “把 XX 做成图片”
- “帮我做个图 / 做张卡片 / 做个海报”
- “帮我做个 PPT / 做个课件”
- “把这段内容做成小红书 / 公众号图”

## 流程（一轮问完，不要分多轮）

1. 先看用户已经说了什么：用途、形态、尺寸、内容处理、风格、输出格式，已提供的直接记下，不再问。
2. 只问缺失的信息，一次合并成 1–3 个问题，用最简单的话。
3. 把你理解的完整计划复述一遍，问一句：“这样可以吗？”
4. 用户确认后再进入对应类型文件生成。

## 缺失信息才问，给最简单的选项

- 用途：小红书 / 公众号 / PPT 演示 / 报告 / 其他
- 形态：一张图 / 多张系列图 / 长图 / 可翻页 PPT / 网页 PPT
- 尺寸：竖版 3:4 / 横版 16:9 / A4 / 手机长图 / 你帮我选
- 内容：照搬原文 / 总结要点 / 混合 / 你看着办
- 风格：默认暖纸红印 / 发参考图 / 文字描述 / 你看着办
- 功能区：封面 / 小标题 / 流程 / 时间线 / 对比 / 数据 / 清单 / 人物 / 引用 / 行动 / 结尾（可多选）
- 美化强度：克制 / 中等 / 丰富 / 你看着办
- 输出：PNG / PDF / 图片集 / HTML / 你帮我选

示例话术：

> 我理解你要做一个小红书多张卡片，内容我帮你总结，风格用默认暖纸红印，最后导出 PNG。
> 尺寸用 3:4 竖版可以吗？

## 铁律

- 用户没说清楚，不要开始生成。
- 一轮问完，不要第一轮问完再问第二轮。
- 用户已经提供的信息，不要重复问，只在最后复述确认。
- 用户说“你看着办”时，选推荐项并明确告知，再开始。
