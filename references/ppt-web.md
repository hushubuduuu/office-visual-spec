# 交互式网页 PPT 生成规范（动态网页 PPT）
## 用户确认（必须先问）

如果用户只说“做 PPT”，先问：

1. 静态图版 PPT：做完是一张张 PPT 图片，可以导出 PDF / PNG，适合直接发出去。
2. 动态网页 PPT：可以在网页上翻页、有动效，适合演示和分享。

本文件是动态网页 PPT；用户确认要动态版后，再按本文件生成。

## 输出与模板

- 模板：`templates/ppt-web.html`
- 导出：`scripts/validate-html.mjs` 自检；PNG/PDF 统一用 `scripts/render-html.py` 标准管线（见 `references/render.md`）
- vw/vh 基准：1vw = 12.8px，1vh = 7.2px

## 模块组装

- 本类型功能区：封面 / 目录 / 内容 / 数据 / 结尾。
- 构成优先于模板：模板是基础底稿，不是唯一答案；先分析内容、选模块、再构成画面，在保持本类型硬规则（尺寸、分页、页边距、无溢出、风格一致）的前提下允许一定自由度，禁止 100% 照搬模板出品；封面页位置自由（左上、居中、右下等均可，见 `references/modules.md` 构成流程），内页按「模块构成自由」。
- 参考与替换：可参考模板中每个模块的大小权重，用同类模块替换（如同一功能区卡片、步骤、清单互换），并按视觉中心逻辑移动位置；替换后仍满足页边距、无溢出、风格一致。
- 模块从 `references/modules.md` 共享库选择，按 `references/modules.md` 的功能区映射。
- 模块尺寸用 `vw` / `vh` 描述，或按本文件 vw/vh 基准换算为固定 px。
- 排版阶段优先级：间距、页边距、对齐 > 模块内容 > 装饰；先完成提问，再按此顺序处理。

## 页面规则

固定 1280×720 画布，等比缩放舞台。

## 组件规范

- 封面：左上红点 + 眉标；右上角使用文档类型标签（如 纪要 / 总结 / PPT / 卡片），不随机放品牌印章；大标题 display 字号字重 800；红色副题 + 下划线；全宽红带；金句卡。
- 页眉：深色 5vw 方块 + 章节标题 + 英文眉标 + 深色线。
- 信息表：白底卡片、1px 描边、圆角 4px、左标签右值、行间浅线。
- 时间线：竖线 0.2vw、圆形徽章 4.4vw、红描边、红色数字。
- 观点页：左侧红条 + 红色眉标 + 姓名双红线；观点用白底卡。
- 行动清单：白底卡、红色描边方块 + 对勾、行间浅线。
- 说明框：白底卡 + 左侧红条；印章：红圆 13vw、白色双线、中心反白两字，内容必须是文档类型（如 纪要 / 总结），不要用品牌词。

## 文字排版硬规则

- 禁止把正文做成图片。
- 中文段落用首行缩进 2em，禁止手动空格。
- 正文 `letter-spacing: 0`；使用 `overflow-wrap: break-word`、`word-break: break-word`。
- 禁止最后一行只剩一个孤字；正文使用 `text-wrap: pretty`，标题使用 `text-wrap: balance`，中文优先在完整词组边界断行。
- 最小字号：PDF ≥10.5pt，PPT ≥14pt，手机长图 ≥36px（1080 基准）。
- 标题层级通过字号、字重、颜色区分，禁止靠装饰堆砌。

## 高级感硬规则

- 底色以白或近白为主，禁止大块深色填充。
- 红色只做强调，禁止大面积铺底。
- 标题用现代无衬线字体，禁止宋体标题。
- 主标题不小于 48px/48pt，人物身份不小于 15px/15pt。
- 卡片必须使用双层阴影（接触阴影 + 环境阴影），避免扁平。
- 禁止大面积红晕/光晕背景。
- 不使用随机品牌印章；文档类型用文字标签（纪要 / 总结 / PPT / 卡片系列）。
- 结尾页必须和开头页同样丰富，不能只放一个印章或一句感谢。
- 文字与卡片边缘保持足够间距，禁止文字贴边。
- 每页只保留一个视觉重点。
- 保留充足留白，禁止内容贴边。
- 无强制水印；署名由用户决定。

### 11.1 卡片款式

- 基础白卡：白底、1px 浅灰描边、圆角 6–10px、柔和阴影。
- 描边卡：无填充、1–1.5px 描边、圆角 8px。
- 浅色块卡：`#F8F6F2` 或 `rgba(211,18,18,0.05)` 底。
- 渐变顶条卡：顶部 4–8px 红到透明渐变线。
- 编号卡：40–60px 淡灰大数字背景。
- 角标卡：右上角小标签，如 `CORE`、`01`、`NOTE`。
- 书签卡：左侧 4–6px 红条 + 右下翻折角。
- 引用卡：大引号 + 引文 + 来源 + 左侧红条。

### 11.2 小标题款式

- 红条标题：左侧 4–6px 红条。
- 序号徽章标题：圆形/圆角方形数字徽章。
- 英文眉标 + 双线标题：上方眉标，下方红短 + 灰长线。
- 色块标签标题：浅红底 pill。
- 装饰引号标题：大号衬线引号。
- 背景水印标题：80–120px 淡灰数字。

### 11.3 色块与装饰

- 强调色块 `rgba(211,18,18,0.06)`；标签 pill；统计大数字。
- 章节色带 2–4px；关键词浅红底。
- 装饰：菱形分隔、双线规则、渐变细线、极浅点阵 ≤5%、纸张纹理 ≤4%、双层阴影、分隔符号 `· - ✦`，禁止 emoji。
- 每页至少 2–4 种装饰，最多不超过 4 种；同层级完全一致；装饰不能遮挡正文。
- 卡片必须用双层阴影增加体积感：接触阴影 + 环境阴影，避免扁平。
- 卡片间距统一管理：同一页面卡片间距一致，块间距大于卡片间距。
- 背景使用近白纸色，禁止大面积红晕/光晕。
- 封面和结尾页必须标注文档类型标签（纪要 / 总结 / PPT / 卡片系列），不要随机放品牌印章。
- 结尾页必须与开头页同样丰富：至少包含回顾清单、核心结论或行动建议。
- 文字与卡片之间保持间距：卡片内 padding 不小于 3vw，卡片外间距按类型统一。

## 页面比例

- 固定 16:9，舞台 1280×720px。
- 使用 `vw` / `vh` 比例体系，不再使用 `u`。

## 构图原则

- 每页一个视觉焦点。
- 四边留白 ≥10%。
- 标题大小至少是正文的 2.5 倍。
- 关键元素可放三分线交点。
- 文字多的页面使用 Z-Pattern：左上 → 右上 → 左下 → 右下。
- 每页最多 3–4 个文字块。

## 阅读型规则

- 每页自解释，不依赖讲者。
- 页面顺序就是阅读顺序。
- 动画优先“进入视野时”触发。

### 7.1 核心原则

- 使用固定 1280×720px 舞台，使用 `vw` / `vh` 比例体系。
- 页面由“原型 + 自适应规则”组成，不写死页码。
- 分辨率变化时由 JS 等比缩放舞台，不改变排版尺寸。

### 7.2 画布

- 固定 1280×720px，16:9。
- JS 按 `scale = min(视口宽/1280, 视口高/720)` 等比缩放。

### 7.3 通用骨架

- 页眉区：顶部约 64px 内，放眉标、标题、页码。
- 内容区：左右边距 80px，主体在顶部 64px 到底部 56px 之间。
- 页脚区：底部 56px 内，放页脚与页码。

### 7.4 页面原型

| 原型 | 内容槽 | 布局 |

## 动效规范

- HTML PPT 用于阅读和分享：每页自解释，顺序即阅读顺序。
- 每页一个 `.sheet`，双写分页规则。
- 动画只使用：淡入、上滑、下滑、左滑、右滑、缩放、旋转、脉冲、抖动、弹跳。
- 触发方式：页面打开、悬停、点击、进入视野；分享型默认优先“进入视野”。
- 时长 0.5–2 秒，循环 1–3 次或无限。
- 每页最多 1–2 个动效重点。
- 动画用 CSS keyframes，不依赖外部 JS 动画库。
- 默认状态必须可见，导出不受动画影响。

## 交互式网页 PPT（ppt-web）

- 模板：`templates/ppt-web.html`。
- **排版架构：固定 1280×720 画布 + 等比缩放舞台（核心设计，与静态 PPT 同基准）**
  - 所有字号、间距、组件尺寸按画布基准用 `vw` / `vh`，不用 vmin。
  - **字号基准**：封面大标题 100px（76px 的 1.3 倍，仅封面）、章节标题 h2 52px、卡片标题 card h3 30px、步骤标题 step h4 32px、正文 20-24px（card p 20 / step p 24）、眉标 kicker 14px、页脚 11px。
  - **行距基准**：标题 1.08、副标题 subtitle 1.6、正文 1.75（卡片与步骤统一）、代码块 1.7。
  - **间距基准**：sheet 内边距 64/80/56px（上/左右/下）；card h3 margin 14px 0 12px；title margin 30px 0 22px（封面 0 0 44px）；step h4 margin 14px 0 12px；grid gap 32px、grid margin-top 48px；卡片 padding ≥3vw≈22px（基准 34/38/30，步骤卡 34/32）；步骤卡 gap 20px；封面按钮行 margin 48px 0 28px、gap 24px；分隔线 rule margin 28px 0 0。
  - **布局硬规则（实测排错结论，不可违反）**：
    1. 垂直居中容器 `.center` 必须用 flex（`display:flex; flex-direction:column; justify-content:center; align-items:center`），**禁止 grid place-items:center**——grid 会把内容行均分拉伸，导致标题被大空隙夹住（视觉"标题太矮"）、卡片行被拉高贴住页脚。
    2. 按钮行（doctype / tag 等）内元素**禁止带独立 margin-top**——flex 行内 margin-top 会把该元素压沉，造成横向不对齐；行间距写在容器上。
    3. 每页 frame 内容**禁止溢出**（`scrollHeight ≤ offsetHeight`）——溢出会挤压左下角页脚。内容超高时优先收紧该页 grid margin-top / 精简文字，禁止全局压缩字号。
    4. 页脚位于 sheet 底部 56px padding 区（90–100vw），内容底距页脚留白 ≥80px；页脚自身 `flex-shrink:0; z-index:2` 防覆盖。
    5. 卡片 / 步骤卡用 flex column + `justify-content:center`，内容不足靠对齐与间距呼吸，不靠撑高卡片。
    6. 步骤卡默认 `text-align:center`（no / h4 / p 居中），消除文字少造成的右侧空洞；深色页必须有 `.sheet.dark .step` 变体（否则浅色文字 + 白卡 = 不可见）。
    7. 深色页幽灵数字透明度 ≤0.045（建议 0.03），避免干扰内容。
  - 外层 `#stage` 固定 1280×720，JS 计算 `scale = min(视口宽/1280, 视口高/720)` 等比缩放居中，视口剩余区域为 letterbox 纸色底（与页面同色，无黑框）；导航条/提示文字随背景色适配。
  - 效果：任何分辨率、任何宽高比下，内容始终 16:9 恒定比例，元素不变形、不撑大、不缩水。**4K 屏 / 笔记本 / 投影仪演示无需缩放浏览器窗口。**
  - 导航圆点、快捷键提示固定在视口（不随舞台缩放）；ESC 索引克隆按 1280 基准缩放。
- **横向翻页引擎**（模板内置，零依赖）：
  - 滚轮（纵向/横向皆可）、键盘 ← → / PageUp / PageDown / 空格 / Home / End
  - 触屏左右滑动
  - 底部圆点导航（点击跳页，当前页红色高亮）
  - ESC 索引总览（网格缩略图，点击跳转）
  - B 键低功耗模式：禁用动效与过渡，静态展示（`localStorage` 记忆，尊重 `prefers-reduced-motion`）
- **动效规范**：
  - 给元素加 `data-anim` 属性 → 进入视野时淡入上滑（stagger 逐元素延迟，由 JS 写 `--d` 变量）
  - `data-anim="left"` / `data-anim="right"` → 左右滑入
  - 页面级节奏：`data-animate="hero"`（封面/深色页，间隔更大）或 `data-animate="cascade"`（默认，逐元素入场）
  - 主题色使用 `--accent-bright` 变量，禁止在 JS/CSS 里硬编码强调色
  - 动画纯 CSS keyframes（`anim-rise` / `anim-left` / `anim-right`），`fill-mode: both`，零外部依赖，file:// 直接打开可用
- **深色页**：`<div class="sheet dark">` 用于章节幕封 / 结尾对比，禁止大面积使用（硬规则 10）。
- **打印降级**：`@media print` 下 stage 解除缩放、deck 转为静态 1280×720 分页，且强制 `[data-anim]` 可见（否则非当前页会空白）。
- **导出**：用 `scripts/render-html.py` 逐页截图；PDF 走打印降级为静态分页。
- **架构对比**：不要用全屏 100vw/100vh + vw/vh 字号的方案（guizang 式）——高分屏下元素会被撑大、比例失控；本模板的固定画布 + scale 是 office-visual-spec 自己的排版哲学延续。

## 常见错误

- 自然高度/自适应类型误用 vh/vmin，导致比例随视口漂移；固定画布类型用 vw/vh 锁基准。
- 长文本一行画完，不允许换行。
- 标题用宋体。
- 长文模式强制分段。
- 正文做成图片。
- 只把分页写在 `@media print` 里。
- 用 `<section>` 做分页容器。

## 导出 PDF / PNG 注意事项

- PNG：按页截图，每页 1280×720；不要整页滚动截图，否则横向 deck 会变成一张长图。
- 导出前切到静态/低功耗模式，或依赖 `@media print` 降级，保证所有页内容可见。
- PDF：浏览器打印 → PDF，打印样式已把横向 deck 转为静态分页。
- 可复制文字 PDF 用 Headless 打印；截图 PDF 仅作视觉稿。

## 交互行为说明

- 滚轮 / 触屏翻页只响应 `#stage` 区域；letterbox 纸色边不触发翻页。
- 键盘翻页全局生效。
- ESC 索引打开时，滚轮不会误翻页。
- 换主题时，`--red` 和 `--accent-bright` 必须一起修改；`--accent-bright` 只用于深色页强调色。

- 标准渲染参数见 `references/render.md`，不要临场发明参数。

风格/颜色不满意时，再读取 `references/style-adjustment.md`，不要整份重写。
