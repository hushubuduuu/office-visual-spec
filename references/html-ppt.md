# HTML PPT 生成规范（静态截图 PPT，一般用于导出 PDF / PNG）
## 用户确认（必须先问）

如果用户只说“做 PPT”，先问：

1. 静态图版 PPT：做完是一张张 PPT 图片，可以导出 PDF / PNG，适合直接发出去。
2. 动态网页 PPT：可以在网页上翻页、有动效，适合演示和分享。

用户确认后，再按本文件生成。

## 输出与模板

- 模板：`templates/ppt-16-9.html`
- 导出：`scripts/validate-html.mjs` 自检；PNG/PDF 统一用 `scripts/render-html.py` 标准管线（见 `references/render.md`）
- vw/vh 基准：1vw = 12.8px，1vh = 7.2px

## 模块组装

- 本类型功能区：封面 / 目录 / 内容 / 数据 / 结尾。
- 构成优先于模板：模板是基础底稿，不是唯一答案；先分析内容、选模块、再构成画面，在保持本类型硬规则（尺寸、分页、页边距、无溢出、风格一致）的前提下允许一定自由度，禁止 100% 照搬模板出品；封面页位置自由（左上、居中、右下等均可，见 `references/modules.md` 构成流程），内页按「模块构成自由」。
- 参考与替换：可参考模板中每个模块的大小权重，用同类模块替换（如同一功能区卡片、步骤、清单互换），并按视觉中心逻辑移动位置；替换后仍满足页边距、无溢出、风格一致。
- 模块从 `references/modules.md` 共享库选择，按 `references/modules.md` 的功能区映射。
- 模块尺寸用 `vw` / `vh` 描述，或按本文件 vw/vh 基准换算为固定 px。
- 排版阶段优先级：间距、页边距、对齐 > 模块内容 > 装饰；先完成提问，再按此顺序处理。

### 5.2 PPT（16:9）

- 画布 1280 × 720px；左右 80px、上 64px、下 56px。
- 标题微软雅黑加粗，正文等线/宋体。
- 每页不超过 4 条清单或 3 个时间线步骤。

### 5.3 HTML

- 使用 CSS 变量保存所有 token。
- 本类型使用固定 1280×720px；宽度用 vw，高度用 vh。
- 提供打印样式 `@page { size: 1280px 720px; margin: 0; }`。

### 5.6 PDF 打印与分页

- 支持 A4、A5、Letter、16:9；四边留白默认上 20mm、下 20mm、左 18mm、右 18mm，其他尺寸按宽度比例换算。
- 允许一页多章节，也允许章节跨页；不设“每页只能一个原型”。
- 标题不能孤立在页尾，标题后至少保留一段正文或卡片。
- 卡片、步骤、清单尽量不断开；段落不能从中间断行。

### 5.7 分页选择

- 全文/连续论述型：连续流动排版，禁止手动拆页，段落保持完整。
- 摘要/阅读型：大量小标题、清单、卡片时，使用 `.sheet` 可读分页。
- 同一文档不得混合两种分页逻辑。

## 组件规范

- 封面：左上红点 + 眉标；右上角使用文档类型标签（如 纪要 / 总结 / PPT / 卡片），不随机放品牌印章；大标题 display 字号字重 800；红色副题 + 下划线；全宽红带；金句卡。
- 页眉：深色 5vw 方块 + 章节标题 + 英文眉标 + 深色线。
- 信息表：白底卡片、1px 描边、圆角 4px、左标签右值、行间浅线。
- 时间线：竖线 0.2vw、圆形徽章 4.4vw、红描边、红色数字。
- 观点页：左侧红条 + 红色眉标 + 姓名双红线；观点用白底卡。
- 行动清单：白底卡、红色描边方块 + 对勾、行间浅线。
- 说明框：白底卡 + 左侧红条；印章：红圆 13vw、白色双线、中心反白两字，内容必须是文档类型（如 纪要 / 总结），不要用品牌词。

## 文字排版硬规则

- 禁止把正文做成图片。
- 中文段落用首行缩进 2em，禁止手动空格。
- 正文 `letter-spacing: 0`；使用 `overflow-wrap: break-word`、`word-break: break-word`。
- 禁止最后一行只剩一个孤字；正文使用 `text-wrap: pretty`，标题使用 `text-wrap: balance`，中文优先在完整词组边界断行。
- 最小字号：PDF ≥10.5pt，PPT ≥14pt，手机长图 ≥36px（1080 基准）。
- 标题层级通过字号、字重、颜色区分，禁止靠装饰堆砌。

## 高级感硬规则

- 底色以白或近白为主，禁止大块深色填充。
- 红色只做强调，禁止大面积铺底。
- 标题用现代无衬线字体，禁止宋体标题。
- 主标题不小于 48px/48pt，人物身份不小于 15px/15pt。
- 卡片必须使用双层阴影（接触阴影 + 环境阴影），避免扁平。
- 禁止大面积红晕/光晕背景。
- 不使用随机品牌印章；文档类型用文字标签（纪要 / 总结 / PPT / 卡片系列）。
- 结尾页必须和开头页同样丰富，不能只放一个印章或一句感谢。
- 文字与卡片边缘保持足够间距，禁止文字贴边。
- 每页只保留一个视觉重点。
- 保留充足留白，禁止内容贴边。
- 无强制水印；署名由用户决定。

### 11.1 卡片款式

- 基础白卡：白底、1px 浅灰描边、圆角 6–10px、柔和阴影。
- 描边卡：无填充、1–1.5px 描边、圆角 8px。
- 浅色块卡：`#F8F6F2` 或 `rgba(211,18,18,0.05)` 底。
- 渐变顶条卡：顶部 4–8px 红到透明渐变线。
- 编号卡：40–60px 淡灰大数字背景。
- 角标卡：右上角小标签，如 `CORE`、`01`、`NOTE`。
- 书签卡：左侧 4–6px 红条 + 右下翻折角。
- 引用卡：大引号 + 引文 + 来源 + 左侧红条。

### 11.2 小标题款式

- 红条标题：左侧 4–6px 红条。
- 序号徽章标题：圆形/圆角方形数字徽章。
- 英文眉标 + 双线标题：上方眉标，下方红短 + 灰长线。
- 色块标签标题：浅红底 pill。
- 装饰引号标题：大号衬线引号。
- 背景水印标题：80–120px 淡灰数字。

### 11.3 色块与装饰

- 强调色块 `rgba(211,18,18,0.06)`；标签 pill；统计大数字。
- 章节色带 2–4px；关键词浅红底。
- 装饰：菱形分隔、双线规则、渐变细线、极浅点阵 ≤5%、纸张纹理 ≤4%、双层阴影、分隔符号 `· - ✦`，禁止 emoji。
- 每页至少 2–4 种装饰，最多不超过 4 种；同层级完全一致；装饰不能遮挡正文。
- 卡片必须用双层阴影增加体积感：接触阴影 + 环境阴影，避免扁平。
- 卡片间距统一管理：同一页面卡片间距一致，块间距大于卡片间距。
- 背景使用近白纸色，禁止大面积红晕/光晕。
- 封面和结尾页必须标注文档类型标签（纪要 / 总结 / PPT / 卡片系列），不要随机放品牌印章。
- 结尾页必须与开头页同样丰富：至少包含回顾清单、核心结论或行动建议。
- 文字与卡片之间保持间距：卡片内 padding 不小于 3vw，卡片外间距按类型统一。

## 构图原则

- 每页一个视觉焦点。
- 四边留白 ≥10%。
- 标题大小至少是正文的 2.5 倍。
- 关键元素可放三分线交点。
- 文字多的页面使用 Z-Pattern：左上 → 右上 → 左下 → 右下。
- 每页最多 3–4 个文字块。

## 阅读型规则

- 每页自解释，不依赖讲者。
- 页面顺序就是阅读顺序。
- 动画优先“进入视野时”触发。

### 7.1 核心原则

- 使用固定 1280×720px 舞台，使用 `vw` / `vh` 比例体系。
- 页面由“原型 + 自适应规则”组成，不写死页码。
- 分辨率变化时由 JS 等比缩放舞台，不改变排版尺寸。

### 7.2 画布

- 固定 1280×720px，16:9。
- JS 按 `scale = min(视口宽/1280, 视口高/720)` 等比缩放。

### 7.3 通用骨架

- 页眉区：顶部约 64px 内，放眉标、标题、页码。
- 内容区：左右边距 80px，主体在顶部 64px 到底部 56px 之间。
- 页脚区：底部 56px 内，放页脚与页码。

### 7.4 页面原型

| 原型 | 内容槽 | 布局 |
| --- | --- | --- |
| 封面 | 品牌、主标题、红色副题、定位语、金句、视觉 | 横屏左 2/3 文字 + 右 1/3 视觉；竖屏视觉上、标题中、金句下 |
| 概览 | 标签+值、核心说明、可选金句 | 横屏左标签右值；竖屏单列堆叠 |
| 人物/观点 | 姓名、身份、引文、重点标题、展开说明 | 横屏上下卡；竖屏依次堆叠 |
| 清单 | 标题、3–5 条清单、备注 | 横屏整页卡或两列；竖屏单列 |
| 流程/课时 | 2–3 个步骤卡，每卡 2–4 条要点 | 横屏并排；竖屏堆叠，卡片顶部红色横条 |
| 金句墙 | 4–6 条短句，可带出处 | 横屏 3×2；竖屏 1–2 列 |
| 结束页 | 品牌、收束语、印章/标识、说明 | 居中构图，外圈细描边 |

## 动效规范

- HTML PPT 用于阅读和分享：每页自解释，顺序即阅读顺序。
- 每页一个 `.sheet`，双写分页规则。
- 动画只使用：淡入、上滑、下滑、左滑、右滑、缩放、旋转、脉冲、抖动、弹跳。
- 触发方式：页面打开、悬停、点击、进入视野；分享型默认优先“进入视野”。
- 时长 0.5–2 秒，循环 1–3 次或无限。
- 每页最多 1–2 个动效重点。
- 动画用 CSS keyframes，不依赖外部 JS 动画库。
- 默认状态必须可见，导出不受动画影响。

## 自检清单

- [ ] 文字可选中、可复制
- [ ] 无溢出、无重叠
- [ ] 分页无空白页
- [ ] 标题不孤立，卡片不拆页
- [ ] 同层级字号、字重、颜色一致
- [ ] 手机长图达到大字标准：正文 ≥36px、主标题 ≥160px（1080 基准）
- [ ] 卡片有双层阴影，不平扁平
- [ ] 每页有 2–4 种装饰
- [ ] 卡片间距一致，文字不贴卡片
- [ ] 封面和结尾页都有文档类型标签
- [ ] 结尾页与开头页一样丰富
- [ ] 背景无大面积红晕/光晕
- [ ] 交互式网页 PPT：每页 frame `scrollHeight ≤ offsetHeight`（无溢出、页脚不被挤压）
- [ ] 交互式网页 PPT：封面标题 100px、按钮行同一水平线
- [ ] 交互式网页 PPT：ESC 索引缩略图内容可见；翻页 / 圆点 / 键盘 / 滚轮可用

## 常见错误

- 自然高度/自适应类型误用 vh/vmin，导致比例随视口漂移；固定画布类型用 vw/vh 锁基准。
- 长文本一行画完，不允许换行。
- 标题用宋体。
- 长文模式强制分段。
- 正文做成图片。
- 只把分页写在 `@media print` 里。
- 用 `<section>` 做分页容器。

## 导出 PDF / PNG 注意事项

- PNG：完整长图 `html-ppt-full.png`，宽度 1280，高度 = 页数 × 720；单页图在 `png/pages/`。
- PDF：分页整本 `html-ppt.pdf`；导出前动画应处于完成态（默认可见）。
- PDF：浏览器打印 → PDF，`@media print` 已做静态降级；截图 PDF 只是视觉稿，不是可复制文字。
- 若需要可复制文字 PDF，用 Chrome/Edge Headless 打印。
- 导出前关闭编辑框线，避免虚线框进入成品。

- 标准渲染参数见 `references/render.md`，不要临场发明参数。
