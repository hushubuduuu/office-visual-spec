# 风格调整流程

## 触发

用户说“风格不好看”“颜色不对”“不够高级”等，不要直接猜。

## 第一步：收集参考

请用户提供：

- 1–3 张参考图，或
- 文字描述：配色倾向、气质关键词、喜欢/不喜欢的元素

## 第二步：提取特征

从参考中提取：

- 主色 / 辅助色 / 强调色
- 字体气质：现代无衬线 / 衬线 / 手写
- 卡片样式：圆角、描边、阴影、色块
- 装饰强度：克制 / 中等 / 丰富

## 第三步：映射到 token

只改这些 CSS 变量：

```css
:root {
  --paper: #...;
  --ink: #...;
  --body: #...;
  --muted: #...;
  --red: #...;
  --divider: #...;
  --card: #...;
  --on-accent: #...;
}
```

## 第四步：重新生成

- 更新模板中的 CSS 变量。
- 保持组件结构、分页规则、字体硬规则不变。
- 重新生成 HTML 并交付预览。
- 用户确认满意后结束；不满意继续收集参考，不整份重写设计体系。
